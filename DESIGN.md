# ImpaExplore interface

The product is an independent tourism discovery and booking-request PWA for Impasugong, Bukidnon. Public discovery is open to guests. A request requires guide confirmation; no payment is collected.

The visual direction is calm editorial travel discovery with practical account workspaces. Use forest green #1B5E20, supporting green #2E7D32, canvas #F4F1EB, surface #FAFAF8, border #E7E5E4, text #20352A and muted text #536156. Gold #CA8A04 is reserved for visible focus.

The content width is fluid up to 1760px. Gutters scale from 18px to 80px. Long prose remains about 72 characters wide. Major headings use clamp; all typography uses the existing sans-serif stack. Surface radii are 12–16px, controls 8–10px. Controls have a 48px minimum height.

Discovery grids grow from one to four columns. One-item results become a horizontal composition on desktop; two items share two columns. Details use a main column plus a 280–360px contextual rail. Account pages use a 248px desktop sidebar, collapsing to wrapped navigation on smaller screens. Auth uses a compact form beside introductory content.

Use permissioned imagery only. Until supplied through the product, media areas explicitly say that imagery is unavailable. Never invent guides, ratings, review claims, prices, locations, or accreditation.

Motion is limited to short feedback transitions and subtle press feedback. Honor reduced-motion preferences. Provide keyboard focus, useful loading/error/empty states, and network-dependent action feedback.
